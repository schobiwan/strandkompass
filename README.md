# Strandkompass

Statische Website zum Bestimmen von Strandfunden an Nord- und Ostsee (Schwesterseite von Vogelkompass und Waldtierkompass).

- Inhalte: `data.py`, Bildnachweise: `credits.json`, Fotos: `photos/` (WebP, Wikimedia Commons)
- Bauen: `npm ci` und `python3 build.py`, Ergebnis in `dist/`
- Hosting: statichost.eu, Einstellungen in `statichost.yml`
